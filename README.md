# Exercices progressives en PHP

Parcours pratique et progressif pour consolider PHP avant d'aborder la programmation orientée objet, PDO, l'architecture backend et les API REST.

## Organisation

Les exercices sont regroupés par notion. Les dossiers futurs ne sont créés que lorsque la notion correspondante sera introduite.

### Progression

1. **01 — Fondations** : exercices 1 à 20
2. **02 — Fonctions** : exercices 21 à 30
3. **03 — Tableaux et manipulation de données** : exercices 31 à 40
4. **04 — Organisation du code** : exercices 41 à 45
5. **05 — Programmation orientée objet** : exercices 46 à 60
6. **06 — Communication entre objets et injection de dépendances** : exercices 61 à 70
7. **07 — SQL, MySQL et PDO** : exercices 71 à 85
8. **08 — Architecture backend** : exercices 86 à 105
9. **09 — HTTP et API REST** : exercices 106 à 120
10. **10 — Authentification et autorisation** : exercices 121 à 135

La sécurité est travaillée progressivement tout au long du parcours.

## Méthode de travail

Chaque exercice suit autant que possible :

**Énoncé → objectif → tentative personnelle → indices → correction → tests → sécurité → commit Git → push**

Le but n'est pas seulement de faire fonctionner le code, mais de comprendre pourquoi chaque élément existe et comment les différentes couches d'un backend communiquent.
